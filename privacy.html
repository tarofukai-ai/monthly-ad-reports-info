1. 取得する情報

利用者が接続を許可したサービスから、次の情報を必要な範囲で取得します。

  • 広告アカウントのID、名称、通貨、タイムゾーン
  • キャンペーン等の名称・識別子、配信区分、取得対象期間
  • 表示回数、クリック数、広告費、コンバージョン等の広告実績と内訳
  • 接続の維持に必要な認証情報
  • レポートの保存先フォルダ・ファイルの識別子と管理に必要な情報

2. 利用目的

取得した情報を、広告実績の取得・集計、月次レポートの作成・保存、数値の照合、接続や処理のエラー対応に使用します。

3. 保存と共有

取得データは処理用の作業領域と、利用者が指定する保存先で取り扱います。認証情報はアクセス制限を設けた場所で管理します。レポートの閲覧範囲は、利用者が指定したGoogleドライブ等の共有設定に従います。

運営者は広告実績や認証情報をこの公開ページに掲載せず、販売しません。処理に必要なAPI提供元、実行環境、保存先のサービスを、当該処理に必要な範囲で利用します。権限を持つ担当者への業務上の共有、利用者が認めた共有、法令に基づく対応を除き、第三者に情報を開示しません。

4. 保管期間と削除

生成したレポートは、利用者が保存先から削除するまで保管されます。処理用の取得データや接続情報については、下記の連絡先から削除を依頼できます。

Googleとの接続はGoogleアカウントの接続管理画面で解除できます。接続を解除しても、作成済みのレポートは自動では削除されません。

5. Google APIのユーザーデータ

Google APIから受け取る情報の利用と他のアプリへの転送は、Limited Useの要件を含むGoogle API Services User Data Policyに従います。

6. 説明ページのアクセス情報

この説明サイトはGitHub Pagesでの配信を予定しています。GitHubはセキュリティ目的等で閲覧者のIPアドレスを記録します。詳しくはGitHubのプライバシーに関する説明をご確認ください。当サイト独自のアクセス解析や広告タグは設置していません。

7. 方針の変更

取り扱うデータや利用目的を変更する場合は、このページを更新し、必要に応じて利用者への説明と再認証を行います。
